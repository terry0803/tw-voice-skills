# tw-voice-skills

這是我自己做的Claude Code skill，改完的中文會比較像台灣人平常寫的。

網路上那些去AI味的工具用了之後還是蠻AI的，看到「此外」「然而」就直接換掉，但是很多詞台灣人自己其實也蠻常用的。我是拿2012到2021年台灣人寫的文章來比，那時候ChatGPT還沒出來。

`tw-everyday-voice`改的是作業、心得、貼文這類平常寫的東西，傳給老師或朋友的訊息也行，拿來比的是13萬多篇部落格跟論壇文章，還有議會跟立法院的逐字稿，論文的版本還在做，等測好再放上來。

## 怎麼裝

把`tw-everyday-voice`這個資料夾放到`~/.claude/skills/`底下就可以用了，之後在Claude Code裡講「這段改自然一點」或「這篇心得太AI了」之類的話，它就會自己用到。

改完它會再對一次數字、名稱跟引號裡的原話有沒有被改掉，原稿沒寫到的經歷它不會幫你編，會問你四到六個問題，像是那天發生了什麼小事、有誰講了什麼，等你回答完再把你講的話放進文章裡。

交稿前它也會一句一句再看一次，看每句是在講發生了什麼，還是在下評語、補理由，下評語的就照做了什麼、結果怎樣重講一次。

給它一整份文件也可以，它會先挑一段試改給你看，覺得可以它才會改完整份，要直接改進檔案的話，它會先把原本的檔案另外存一份`_改前`。

## 更像你自己

它也會照你自己講話的習慣換說法，但是`references/個人語感.md`這份要各位自己做，範本放在`references/個人語感_範本.md`，我自己是錄了一段幾分鐘的口述，用`scripts/dictate.py`轉成文字以後，再去看自己常用哪些詞、句子都怎麼接，沒有這個檔的話這一步就會跳過。

## 自己跑程式

不用另外裝套件，有Python 3就可以跑，我自己是用3.13。

```
python scripts/check.py 稿子.txt --kind casual     # 作業、說明
python scripts/check.py 稿子.txt --kind speech     # 貼文、訊息
python scripts/fidelity.py 原稿.txt 改寫稿.txt     # 對數字、名稱、原話有沒有被改掉
```

稿子可以是txt、md或docx。

有些功能要另外裝東西才能執行，沒裝的話就會自己跳過，如果想讓它讀文章裡的人名、地名或時間，要裝ckip-transformers，想把錄音轉成文字的話要裝faster-whisper，裝好之後把python的路徑填在環境變數`TW_VOICE_NLP_PY`跟`TW_VOICE_STT_PY`裡程式就能找到，`--topic`會拿同主題的真人文章來參考，但是語料沒有放在這裡，自己有語料的話可以把資料夾路徑填在`TW_VOICE_CORPUS`

## 準不準

我先拿八成的語料訂規則，剩下兩成等規則都訂好了才拿出來測。

| | AI寫的被抓出來 | 台灣人寫的被當成AI |
|---|---|---|
| 舊的Claude稿 | 98% | 12% |
| ChatGPT回答 | 56% | 1% |
| 現在的Claude寫的心得、貼文 | 67% | 4.1% |
| 一直交代理由跟目的 | 舊的Claude稿35% | 2.4% |
| 句子切太碎、講太省 | 現在的AI稿16–28% | 9% |

右邊那欄是台灣人自己寫的文章被當成AI的比例，像第一列的12%，就是一百篇真人寫的文章裡大概有12篇會被誤會。

句子切太碎那項是看有沒有15個字以上、一口氣講完的長句，叫AI寫自然一點的時候這種長句反而會變少，改完它會再量一次。

規則全部一起看的話，台灣人寫的文章也有18.1%會被標出來，被標到不一定就是AI。

我也有請模型當評審，拿改出來的稿子跟幾個別人做的skill比，對Humanizer-zh-TW跟humanizer-zh大概贏八成多，跟說人話speak-human-tw比的話，改現在的模型寫的心得是我們比較好，改ChatGPT的問答回覆是說人話比較好，我自己也盲測過，兩邊字數差不多的時候其實分不太出來，十題只對四題。

## 評審猜得出來嗎

我還有請模型當評審猜一篇文章是人寫的還是AI寫的，一次只給它看一篇，真人的文章是從沒拿來訂規則的部落格裡挑的，AI的是先把那篇文章整理成重點，再請AI照重點重寫一篇。

| 給評審看的文章 | Opus猜是人寫的 | Sonnet猜是人寫的 |
|---|---|---|
| 台灣人寫的部落格文章 | 100% | 100% |
| AI照重點寫的文章 | 0% | 38% |
| AI寫的再用這個skill改過 | 12% | 63% |
| 改完再加幾句作者自己講的話 | 8% | 100% |
| 真人寫的文章用這個skill改過 | 88% | 100% |

Sonnet只要作者自己補幾句話就分不出來了，Opus就很難騙，字句是AI想的它幾乎都認得出來，但是同一套改法拿去改真人寫的文章，它有88%猜是人寫的。想騙過很嚴格的讀者，還是要各位自己打草稿或錄音講一遍，再讓skill整理，每一組只有24篇，評審也是模型，數字參考就好，細節在`tw-everyday-voice/references/像真人測試.md`。

## 還做不到的

- 內容是AI寫的就是AI寫的，痕跡它可以改掉，真的經歷它補不出來，這部分還是要各位自己改改。
- 語料大部分是部落格，PTT、Dcard那些網站不給AI抓，都沒有收到。
- 拿來比的ChatGPT是2022年的GPT-3.5，比現在的模型舊。
- 它蠻耗token的，用一次光是讀SKILL.md就大概要4到5萬，加上程式跑出來的報告，一次大概5到7萬，稿子長的話還會更多，用之前各位可以先看一下自己的額度。

## 資料

語料是FineWeb-2（ODC-By）裡的台灣網頁、照robots.txt抓的部落格跟論壇，還有議會跟立法院的公開逐字稿，AI的對照稿是HC3資料集裡的ChatGPT回答，還有我自己以前請Claude寫的稿子，原文都只放在我電腦上算統計，這裡只有算出來的數字，skill裡的例句也都是我自己寫的。
